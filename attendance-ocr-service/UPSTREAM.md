# Source Origin

Based on https://github.com/palmaus/attendance-ocr-service.git at commit
`bde4a4e71356c3932cdb26a65686e921e047d7be`.

The source and LMS integration changes are included as ordinary files in
the summer_2026 repository, not as a submodule. A local nested `.git` may
exist on the original development computer; it is not required to run the
service and must not be included in commits.

Virtual environments, uploaded photos, runtime databases, caches and model
weights are not distributed with this source snapshot.
